Privacy policy

Alma & Hermine Publishing Studio (Meta app “Alma Hermine Publisher”) · last updated 2 November 2026

Who uses this application

Alma & Hermine Publishing Studio is a personal desktop tool. It is used only by its owner, the person who runs the Alma and Hermine Facebook Page and YouTube channel, to publish the owner's own videos. It is not offered to the public and no other person can sign in to it.

What data the application uses

  • Facebook: the owner's Facebook user ID and name; the ID, name, category and the owner's role (tasks) on the Pages the owner manages; the access token of the one selected Page (Alma and Hermine); and the permissions the owner granted (pages_show_list, pages_read_engagement, pages_manage_posts). These are used only to show which Page is connected and to publish Reels to it when the owner explicitly confirms each one.
  • YouTube (Google): the owner's YouTube channel ID and name, and an access/refresh token. They are used only to upload the owner's videos when the owner explicitly confirms each upload.
  • Content: the owner's own videos, captions, music choices and publishing history, kept on the owner's computer.

Where the data is stored

All data stays on the owner's own Windows computer. Access tokens and app secrets are encrypted with Windows Data Protection (DPAPI) so that only the owner's Windows account can read them. The application has no server and no database outside the owner's computer, and it does not send data to anyone except Meta and Google when the owner uses their official APIs.

What the application does not do

  • It does not collect or process data about other Facebook or YouTube users.
  • It does not sell, rent or share data, does not use data for advertising and has no analytics or tracking.
  • It never posts anything without the owner's explicit confirmation for that single video.

This website

These pages are static files hosted by GitHub Pages. They use no cookies, no analytics and no third-party content. The Facebook login callback page (oauth.html) only displays a one-time login code so the owner can copy it into the desktop application. It does not store or send it anywhere. GitHub may log visits to its servers, as described in the GitHub privacy statement.

Retention and deletion

Data is kept on the owner's computer until the owner disconnects the account in the application or deletes it. See data deletion instructions.
