User data deletion instructions

Alma & Hermine Publishing Studio (Meta app “Alma Hermine Publisher”) · last updated 2 November 2026

The application stores data only on its owner's own computer. It has no server, so no data about you is held by this application anywhere else. To remove the application's access and delete its data:

1. Remove the app's access on Facebook

  1. Open Facebook → Settings & privacy → Settings.
  2. Open Business integrations (or Apps and websites).
  3. Select Alma Hermine Publisher and choose Remove. This revokes all access tokens immediately.

2. Delete the data in the application (owner)

  1. In Alma & Hermine Publishing Studio: Settings → Connections → DISCONNECT FACEBOOK. This deletes the stored Facebook tokens and asks Meta to revoke the app's permissions.
  2. Optional: delete the folder %APPDATA%\AlmaHerminePublisher on the owner's computer to remove all stored (encrypted) credentials.
